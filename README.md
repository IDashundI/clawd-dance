# clawd-dance

Клодик, маскот Claude Code, танцует в отдельной панели рядом с чатом. Пока Claude работает над запросом,
он танцует в два раза быстрее, а между запросами пританцовывает спокойнее. Панель открывается сама при старте
сессии (если терминал достаточно широкий), а вручную её можно открыть командой `/dance`.

## Установка

В терминальной сессии Claude Code:

```
/plugin install clawd-dance --marketplace IDashundI/clawd-dance
```

Дальше `y`, чтобы добавить маркетплейс, и выбрать область (scope).

Из обычного терминала:

```
claude plugin install clawd-dance --marketplace IDashundI/clawd-dance
```

В десктопном приложении, где `/plugin` не работает: нажать + рядом с полем ввода, потом Plugins, Add marketplace с `IDashundI/clawd-dance`, потом Add plugin.
